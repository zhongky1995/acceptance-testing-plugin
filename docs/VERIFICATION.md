## 0.3.0 风险与证据程序约束（2026-10-16）

- 102 项离线测试在 Python 3.10.19 / 3.14.6 通过；在原有 73 项基础上增加 29 项。覆盖强制适用矩阵、按内容去重的代表性输入、真实双向契约、逐点/逐样本绑定、单次与持续主张、请求/token/费用及观察窗口。
- 离线契约演示直接调用示例生产/消费函数，发现合法上界被消费方拒绝；修复隔离副本后新轮通过。原审批缺陷演示继续通过预期的 failed → 新轮 passed 路径；均不获得产品整体结论。
- 新增观察数据是明确标注的合成协议测试夹具；未声称本轮执行了真实浏览器用户测试，也未调用付费服务或目标业务项目。
- 预算反例覆盖未结算 check 预留、重复 check 幂等、失败请求计费、未知价格保留上界、漏账本受阻、显式复用不重复计费、篡改派生计量回读失败。有限持续观察同时验证缺次数/窗口拒绝和实际重复通过的正向路径。
- 七个技能通过 quick_validate；本地 Markdown 引用、双 manifest 版本及发行包校验通过。GitHub CI 继续在 Ubuntu/Python 3.10 与 3.14 上检查完整离线测试、审批演示和打包；契约演示由测试调用。

本轮没有新依赖安装。费用账本只覆盖已登记测试活动，宿主规划与对话成本未自动获取。语义真实性、完整需求发现、真实适配器可信度、跨模型实际遵循及长期业务效果不在这些测试的证明范围内。

## 0.2.0 交互与程序防漏（2026-10-09）

增加独立交互技能及 schema 1.1 程序协议，保持 Python 标准库运行。三类结论由程序分别计算，自动检查任务/路径/状态覆盖、观察前记录、逐点证据和产品门禁范围。

- 73 项离线测试在本地 macOS、Python 3.10.19 与 3.14.6 上通过；其中 37 项新增检查覆盖后端单独通过、可选交互、漏状态、范围缩小、接口冒充界面、Agent 冒充用户观察、无效/重放检查记录、无轨迹、旧档案以及独立进程接手续跑、混合断言逐点展示、逐点重试不稳定和损坏证据不可放行等场景。
- 纯 API 服务可有依据地声明交互不适用；局部检查可延期无关状态并保留理由，但产品门禁仍拒绝把 focused 通过当成 product 通过。
- 七个技能通过 quick_validate，42 条插件内 Markdown 引用有效。校验复用系统已有 PyYAML，插件运行未新增依赖。
- 既有审批规则演示仍保留初轮 failed、新轮修复 passed；这是 focused 规则检查，不获得完整产品通过。
- 新协议完成一次真实 Codex 内置浏览器取证：先记录需求与任务基线、取得 U1 先行检查记录，再实际点击本人审批；页面返回 approved。真实截图、页面可访问性状态和六个检查点导入后，结果为 need_fit=passed、interaction=failed、implementation=not_assessed、product_accepted=false。该失败是样例故意保留的规则缺陷，不是协议运行失败。
- 浏览器取证档案保存在本地 dist/interaction-browser-20261009，未纳入公开包；临时服务与页面已关闭。该样例的 PRD 不承诺 Web 交付，本轮明确只验证临时入口与取证协议。

验证边界：协议测试中的合成观察仅是内核测试数据，不是真实用户结果；独立进程验证不等于多个模型的实际遵循测试。程序无法证明语义判断、身份声明真实，也不能约束宿主绕过 gate 或同权限篡改。旧 schema 1.0 保留为历史，不伪装成已满足新协议。

## 验证限度

- 当前证明 Python 本地执行内核、六个技能静态有效性、审批样例和一个宿主的浏览器取证路径。
- 不证明全部模型/宿主可正确遵循技能，不证明所有测试框架 CLI 参数有效。JUnit/Playwright 的报告解析不等于自带这些框架。
- 独立 Agent 前向验证因工具未回显指定模型与推理强度，按用户与仓库派单约定停止；未把该验证记为通过。
- 尚未进行真实客户项目的性能、安全、私有化部署、收费外部服务和多客户复制演练。专项方法已提供，按目标与现有工具启用。
- 宿主模型费用未获得完整计量。验证未调用被测项目的收费外部服务，不将此写成宿主推理费用为零。
