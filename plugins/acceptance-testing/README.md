# 验收测试

七个按需技能与基于证据的验收执行工具，面向通过 AI 开发产品的负责人。默认复用现有环境，先确定本轮标准和预算，再执行必要测试与生成报告。

业务检查区分定义/标准依据、实现符合性和真实业务效果，按[业务分析与校验](references/business-validation.md)处理多角色价值、AI 内容及反馈归属。必要检查进入现有门禁，程序不自动判断语义或商业价值。

需要 Python 3.10+ 标准库及宿主已有的文件、命令或浏览器能力。插件不自动安装测试框架，不另接模型 API。不同模型和宿主的实际支持范围以已验证记录为准。

安装后可描述：

> 用验收测试检查我的项目。这是持续开发中的本地产品，本轮重点验证审批规则和相关回归。复用已有环境，先说明预计投入，执行后给我报告。

完整安装说明、使用示例、验证范围与反馈入口：

[GitHub 仓库](https://github.com/zhongky1995/acceptance-testing-plugin)

每轮证据默认保存在目标项目的 .acceptance 目录。分享档案前检查敏感信息。tests/fixtures 中的审批程序故意含缺陷，只用于隔离测试。
