# 共享工作约定

## 本轮合同

项目目录、目标、阶段、范围、标准来源、时间与费用约束是本轮事实来源。用户最新明确要求优先，现有授权继续有效。只对无法查明且改变方向、权限、成本或业务规则的未知询问，独立工作继续。

常规入口默认一个 Agent。七个技能按触发读取，不默认派发其他任务或依赖多模型服务。需要独立评审或并行时遵循宿主及项目授权、模型选择规则和预算。

## 目标与事实

产品文档说明期望，架构与代码说明实现，执行记录说明被验证的行为。需求与实现冲突是缺口，不能自动以实现为准。每项要求记录来源与 confirmed/proposed/conflict。部分标准缺失只限制相关结论，不阻断无关检查。

业务验收还需检查期望本身的依据：角色、问题、价值和分工可以是待验假设，按 [业务分析与校验](business-validation.md)复用项目定义与案例，分别给标准依据、实现符合性和本轮真实效果结论。假设被反证、规则缺口和代码违约分开处理；不自动重做产品设计或更改已确认目标。

三种场景：本地迭代默认复用；第三方接手默认只读预检；目标交付按承诺升级实测。阶段和项目类型叠加，不复制多套规则。风险、目标及已有证据决定力度，来源本身不是安装或全量测试理由。

## 运行边界

`scripts/qa.py` 使用 Python 3.10+ 标准库。没有 Python 时优先检查宿主现有解释器；缺少则说明运行能力受限，不能静默安装。解释器选定后整轮一致。

项目脚本必须实际检查其副作用。执行工具的 argv 直接传入进程，不拼接 shell；但任何命令都可能执行任意代码，工具不是安全沙盒。外部调用/安装声明需要代理如实填写，并遵循宿主权限。

时间预算计算实际执行累计，不包含等待用户的空闲。命令超时和每用例尝试数可强制执行；模型费用、原生 computer use 的调用费用和运行时间来自宿主或人工记录，无法强制拦截宿主工具。费用上界是保守占用，不伪装成实测；超过或未知时停止扩展并保留结果。

## 状态与恢复

passed/failed/blocked/skipped/not_run/flaky 分别统计。依赖失败只影响关联项。默认 `run` 继续尚无结果的命令；已有失败或受阻须复核后 `--case ID --retry`，不能无限重跑。执行中断恢复前检查进程和业务状态，防止重复影响。

方案开始执行后冻结。改标准、代码、依赖、外部环境或模型需新轮，记录旧用例/缺陷关联。该版本不会自动跨轮将旧结果当门禁通过；历史结果可供规划引用，有效性须重新核查。

## 输出

确定性门禁只覆盖本轮 required 用例与要求，范围外不影响也不代表通过。非门禁失败照常展示。验收不自带修复、生产发布或真实外部操作权限。用户要亲自测试时只启动环境和可访问性检查。

[程序验收协议](acceptance-protocol.md)自动推导三类验收、任务路径和适用状态的必要覆盖，readiness 列缺项，check 发本次观察记录，record 留证，report 重核验。完整放行由 gate/product_accepted 控制；focused 通过只是限定范围通过。协议保障记录和流程一致性，不保证语义判断真实，也不控制绕过插件的外部发布。
